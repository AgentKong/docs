## What is Cortana Claw?

**Cortana Claw** is Cortana's AI agent workforce. You create agents for your business, and those agents complete real tasks for you — researching, pulling your attribution and revenue data, operating a browser, running on a schedule, working toward goals, and reporting back in the app or in Slack.

Think of a Claw agent as a teammate that can use your tools, remember what it learns, and repeat procedures reliably.

<Note>
  **Claw agents are not the same as the AI Agents feature.** The conversational **AI Agents** product chats with *your leads* and books appointments. A **Claw** agent works for *you*, the operator. Different products, different jobs.
</Note>

## Where agents can run

A Claw agent has three possible "bodies". You pick where a task runs when you send it.

<AccordionGroup>
  <Accordion title="Cloud — the default, works in any browser" icon="cloud">
    Agents run on Cortana's servers with full access to your connected data (attribution, Stripe, Shopify, contacts, calls, YouTube, and any tools you connect) plus web search. No desktop app needed, and cloud runs work from any browser and from Slack. Cloud runs **cannot** drive a browser or control your computer.
  </Accordion>

  <Accordion title="Desktop — browser and computer control" icon="laptop">
    With the Cortana desktop app installed, agents can browse the web in a real browser, control your screen, work with native apps, and run scripts on your machine. Every sensitive action asks for your approval first.
  </Accordion>

  <Accordion title="Chrome extension — your logged-in browser" icon="chrome">
    The Cortana Chrome extension lets an agent drive a specific Chrome profile — useful when a task needs your existing logged-in browser sessions.
  </Accordion>
</AccordionGroup>

See [Desktop, cloud & extension](/claw/desktop-cloud-extension) for the full comparison.

## Ways to put agents to work

| Surface | What it is | Where |
|---|---|---|
| **Threads console** | Chat with an agent and watch it work, with persistent sessions. | The workspace home. See [Getting started](/claw/getting-started). |
| **Loops** | Recurring scheduled tasks and standing goals the agent loops toward. | Loops tab. See [Automations](/claw/automations). |
| **Recipes** | Bundle skills, tools, and schedules into a reusable setup, or install one. | Recipes tab. See [Recipes](/claw/recipes). |
| **Slack** | Type `/cortana <task>` in a connected workspace; get progress and results in the thread. | Any connected Slack channel. See [Slack](/claw/slack). |

## The safety model

Claw is built **approval-first**. Actions that touch the outside world — clicking, submitting forms, running commands, saving memories, connecting tools — pause and ask you before they happen. Read-only actions (reading pages, searching, recalling past work) never need approval. Unattended runs are opt-in per task.

<Warning>
  Nothing sensitive happens silently. If an agent is about to do something that changes data or reaches outside Cortana, it stops and asks — unless you explicitly turned on **Unattended** for that run. See [Approvals & billing](/claw/approvals-and-billing).
</Warning>

## FAQ

<AccordionGroup>
  <Accordion title="Is Cortana Claw the same as the AI Agents that talk to my leads?">
    No. **AI Agents** are customer-facing (they chat with leads and book appointments). **Claw** agents work for you — they use your tools, pull your data, and run tasks. Two separate products.
  </Accordion>

  <Accordion title="Do I need to install anything?">
    No — cloud runs (data, research, reporting) work in any browser. Install the desktop app only for browser or computer-control tasks, or the Chrome extension to use your logged-in browser.
  </Accordion>

  <Accordion title="Can one agent work across several of my businesses?">
    Yes. An agent is business-owned but can be attached to more than one business, and agency admins can share a single agent across businesses. Each business can mark one agent as its **default**.
  </Accordion>

  <Accordion title="Will an agent do something without asking me?">
    Only if you turn on **Unattended** for that run. By default every sensitive action waits for your approval, and you can press **Stop** at any time.
  </Accordion>

  <Accordion title="What does it cost to run an agent?">
    Runs are billed per token against your Cortana credit, or **$0** if your business supplies its own Anthropic (Claude) API key. See [Approvals & billing](/claw/approvals-and-billing).
  </Accordion>
</AccordionGroup>
