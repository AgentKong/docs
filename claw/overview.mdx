## What is Cortana Claw?

Cortana Claw is Cortana's AI agent workforce. You create agents for your business, and those agents complete real tasks for you: researching, pulling your attribution and revenue data, operating a browser, running on schedules, working toward goals, and reporting back in the app or in Slack.

Claw agents are different from the conversational **AI Agents** feature (which chats with your leads and books appointments). A Claw agent works *for you*, the operator: think of it as a teammate that can use your tools, remember what it learns, and repeat procedures reliably.

## Where agents can run

A Claw agent has three possible "bodies":

- **Your desktop** — with the Cortana desktop app installed, agents can browse the web in a real browser, control your screen, work with native apps, and run scripts on your machine. Every sensitive action asks for your approval first.
- **The cloud** — agents run on Cortana's servers with full access to your connected data (attribution, Stripe, Shopify, contacts, calls, YouTube, and any tools you connect) plus web search. No desktop app needed, and cloud runs work from any browser and from Slack.
- **Your Chrome browser** — the Cortana Chrome extension lets agents drive a specific Chrome profile, which is useful when a task needs your logged-in browser sessions.

## What agents can use

- **Your Cortana data**: attribution, UTMs, Stripe/Shopify/Whop revenue, contacts, conversations, call recordings and meeting transcripts, form submissions, and YouTube analytics.
- **Connected tools**: add almost any remote MCP tool server, shared across all your agents or private to one agent. See [Connecting tools](/claw/connectors).
- **Skills**: reusable step-by-step playbooks the agent follows. You can even teach a skill by demonstrating it once. See [Skills](/claw/skills).
- **Memory**: agents recall their past work and can save durable facts with your approval. See [Agent memory](/claw/memory).

## Ways to put agents to work

- **Run console** — chat with an agent and watch it work step by step, with persistent conversation sessions.
- **Automations** — recurring scheduled tasks and standing goals the agent loops toward. See [Automations](/claw/automations).
- **Recipes** — bundle skills, tools, and schedules into a reusable setup, or install one from the marketplace. See [Recipes](/claw/recipes).
- **Slack** — type `/cortana <task>` in a connected Slack workspace and get progress, approvals, and results in the thread. See [Using Claw from Slack](/claw/slack).

## Where to find it

Open your business in Cortana and go to the **Agent** section. The Run console is the home view; the left rail gives you **Automations**, **Recipes**, and (on the desktop app) **Chrome profiles** and **Local LLM**. Agents and Skills are managed from the console.

## Safety model

Claw is built approval-first. Actions that touch the outside world — clicking, submitting forms, running commands, saving memories, connecting tools — pause and ask you before they happen. Read-only actions (reading pages, searching, recalling past work) never need approval. Unattended runs are opt-in per task. See [Approvals and billing](/claw/approvals-and-billing).
