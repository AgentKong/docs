## REST API keys

API keys authenticate the public REST API and any integration you build yourself. Every request sends the key as a Bearer token. Keys are shown once and start with `sk-ak-`.

<Steps>
  <Step title="Open Settings">
    Go to Settings, then API Keys, then Generate New Key in your Cortana dashboard.
  </Step>
  <Step title="Pick a permission preset">
    Choose one of two one-click presets, or set permissions a la carte. New keys default to Read Only.
  </Step>
  <Step title="Generate and copy">
    Give the key a name, click Generate, and copy it immediately. It will not be shown again.
  </Step>
</Steps>

### A la carte scopes

Instead of a preset, scroll the permission list and check the specific scopes you need, then click Generate. Each scope below is one of those a la carte options.

| Scope | Grants |
| --- | --- |
| `contacts:read` | List and search contacts |
| `contacts:write` | Create, update, and delete contacts |
| `conversations:read` | List conversations, read messages and call logs |
| `conversations:write` | Update conversation metadata |
| `messages:read` | Read message history |
| `messages:write` | Send messages |
| `agents:read` | List and view agent configurations |
| `agents:write` | Create, update, and delete agents |
| `appointments:read` | List and view appointments |
| `appointments:write` | Create, update, and delete appointments |
| `conversions:read` | View conversion entries and configs |
| `conversions:write` | Create conversion entries |
| `tracking:read` | View tracking sessions |
| `tags:read` / `tags:write` | Manage tags |
| `custom_fields:read` / `custom_fields:write` | Manage custom fields |
| `attribution:read` | Full attribution table, UTMs, presets, LTV |
| `stripe:read` | Stripe payments, subscriptions, customers, metrics |
| `shopify:read` | Shopify orders, customers, products, analytics |
| `whop:read` | Whop payments, customers, memberships |
| `meetings:read` | Read meetings and Fathom data |
| `businesses:write` | Create businesses and list agency business templates |

<Note>
  Programmatic onboarding (`businesses:write`) is included in All Access, or you can select it on its own a la carte.
</Note>

### Find your Business ID

Most routes are per business (`/api/v1/businesses/{businessId}/...`). Your Business ID is in the dashboard URL:

```text
https://app.usecortana.ai/business/cf3383a0-55f6-45d8-ab57-484edd63770c/tracking
```

The UUID after `/business/` is your Business ID.

## Connecting an AI assistant (MCP)

To use Cortana inside Claude, ChatGPT, or Codex, add the MCP connector. This path uses OAuth, so there is no API key to copy or store.

<Steps>
  <Step title="Add the connector">
    In your AI tool, add a custom connector using the MCP URL `app.usecortana.ai/api/mcp`.
  </Step>
  <Step title="Log in to Cortana">
    You are sent to Cortana to sign in, the same account you use for the dashboard.
  </Step>
  <Step title="Pick your businesses">
    Choose which business or businesses the assistant is allowed to access.
  </Step>
  <Step title="Approve permissions">
    Review the consent screen and approve. Ad analytics is granted by default.
  </Step>
</Steps>

<Warning>
  Ad management (create, launch, and spend) is a separate opt-in checkbox on the consent screen. Leave it unchecked if you only want the assistant to read data.
</Warning>
