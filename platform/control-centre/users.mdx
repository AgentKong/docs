## Managing Users in Cortana

The Cortana platform provides a flexible user management system, allowing you to control access for your team members, employees, or clients at both a global and business-specific level. This guide explains how to add, edit, and manage user permissions from the Control Centre and within individual business settings.

## Understanding User Roles

Cortana has two primary user access levels that determine what a user can see and do within the platform:

- **Manager:** This role has restricted access. Managers can only view and manage the specific businesses that are assigned to them. They **cannot** access the main Control Centre (Users, Analytics, Settings, etc.). This is the ideal role for team members or clients who only need to work within certain business accounts.
- **Admin:** This role has full administrative privileges. Admins can view, create and delete businesses within the account. They also have complete access to the Control Centre, allowing them to manage all users, view analytics, and change settings.

## Managing Users from the Control Centre (Global Management)

The Control Centre provides a centralized location to manage all users across all of your businesses.

### Adding a New User

1. Navigate to the **Control Centre** and click on **Users** in the left-hand menu.
2. Click the **Add New User** button in the top right corner.
3. A "Create User" pop-up will appear. Fill in the following details:
   - **Name:** The user's full name.
   - **Email:** The user's email address, which they will use to log in.
   - **Password:** Create a secure password for the user.
   - **Access Level:** Choose either **Manager** or **Admin** from the dropdown menu.
4. Click **Create**. The user will now appear in your global user list.

### Editing User Details and Assigning Businesses

1. In the "Users" list, click the **edit icon** (a pencil) next to the user you wish to manage.
2. This will take you to the **User Details** page, where you can:
   - **Edit User Information:** Click **Edit User** to change their name, email, or access level.
   - **Reset Password:** Click **Reset Password** to set a new password for the user.
   - **Assign Businesses (for Managers):** In the "Assigned Businesses" section on the right, you can control which businesses the manager can access.
     - **To Assign:** Click the **+ Assign** button, select one or more businesses from the list, and click **Assign**.
     - **To Unassign:** Click the **delete icon** (a trash can) next to the business name you want to remove.

### Deleting a User

To permanently remove a user from your account:

1. In the main "Users" list, click the **delete icon** (a trash can) in the "Actions" column for that user.
2. You will be prompted to confirm the deletion by typing "DELETE". This action is irreversible and will remove all of the user's data and access.

## Managing Users from Business Settings (Specific Management)

You can also manage which users have access to a single, specific business. This is useful for quickly adding a team member or client to the business you are currently working on.

1. Select the desired business from the dropdown menu at the top of the left-hand navigation bar.
2. Click on **Settings**.
3. Navigate to the **Users** tab.
4. Here, you will see a list of all users who currently have access to *this business only*. You can also add a new user to this business by clicking "Add User"

## Turning off API and AI tools for one person

{/* last-verified: 2026-10-06 · app: Control Centre > Users > user > Manage Permissions (permission key apiAccess) */}

You can stop one team member from using the Cortana API and AI assistants (Claude, ChatGPT) without removing them from your account. Their API keys and AI connections stop working on their next request. Nothing is deleted, so you can switch it back on at any time.

1. Go to the **Control Centre** and click **Users**.
2. Click the **edit icon** (a pencil) next to the team member.
3. On their **User Details** page, click **Manage Permissions**.
4. Find **API & AI tools** and switch it off. You can also untick **Use API keys and AI tools** inside it: either one turns it off.
5. Click **Save Permissions**.

You can also change it from **Settings** > **Users** inside any business the person belongs to. Either way, it applies to the person everywhere, not to one business.

<AccordionGroup>
  <Accordion title="What stops when API and AI tools is off">
    From the person's next request:

    - Every API key they made stops working. The Cortana API answers with "Your account admin has turned off API and AI tools for you."
    - Their Claude and ChatGPT connections to Cortana stop working, and they cannot connect a new one. The Cortana sign-in screen shows the same sentence.
    - They cannot create a new API key. Their **API Keys** page and the AI connection screens show the sentence instead of the create and connect buttons. Their existing keys and connections stay listed, and they can still remove them.

    Logging in to the Cortana dashboard is not affected.
  </Accordion>

  <Accordion title="Who it applies to">
    It applies to team members (Managers and Admins). The account owner always keeps API and AI tools, and you cannot change your own permissions.
  </Accordion>

  <Accordion title="The Chrome extension keeps working">
    When the person signs in to the Cortana Chrome extension with **Sign in with Cortana AI**, the extension uses its own key, which is not affected: the Ads Manager overlay, tracking links and payment links keep working. If they connected the extension with **Connect with API Key** instead, that pasted key is one they created, so it stops with the rest. They can reconnect with **Sign in with Cortana AI**, which works while the switch is off.
  </Accordion>

  <Accordion title="Switching it back on">
    Switch **API & AI tools** back on and click **Save Permissions**. Their API keys work again straight away. A Claude or ChatGPT connection may ask them to reconnect once, because the assistant drops a connection that was refused while the switch was off.
  </Accordion>
</AccordionGroup>

### FAQ

<AccordionGroup>
  <Accordion title="My teammate's Zapier stopped working and says the account admin turned off API and AI tools">
    Their **API & AI tools** permission is off. An admin can switch it back on from **Control Centre** > **Users** > the person > **Manage Permissions**.
  </Accordion>

  <Accordion title="Does turning this off delete their API keys?">
    No. The keys stay, they just stop working until the switch is back on. The person can still delete them from their **API Keys** page.
  </Accordion>

  <Accordion title="Can I turn off AI tools but keep the Chrome extension?">
    Yes, when the extension is connected with **Sign in with Cortana AI**: it keeps working while API and AI tools is off. An extension connected with a pasted API key stops, so reconnect it with **Sign in with Cortana AI**.
  </Accordion>
</AccordionGroup>
