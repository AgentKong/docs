Most people connect with the hosted connector over OAuth, no API key needed. Power users can also run the connector locally with an API key.

## Option 1: Hosted connector (recommended)

<Steps>
  <Step title="Add the connector">
    In your AI tool, add a custom connector using the MCP URL `https://app.usecortana.ai/api/mcp`. In Claude.ai this is Settings, then Connectors, then Add custom connector.
  </Step>
  <Step title="Log in to Cortana">
    You are sent to Cortana to sign in, the same account you use for the dashboard.
  </Step>
  <Step title="Pick your businesses">
    Choose which business or businesses the assistant is allowed to access.
  </Step>
  <Step title="Approve permissions">
    Review the consent screen and approve. Ad analytics is granted by default.
  </Step>
</Steps>

This works in Claude (web and desktop), ChatGPT, Codex, and any client that supports remote MCP connectors. The assistant discovers every Cortana tool automatically.

## Read vs manage

<CardGroup cols={2}>
  <Card title="Read (default)" icon="eye">
    Attribution, revenue, CRM, sales calls, and YouTube data. Granted as soon as you connect.
  </Card>

  <Card title="Manage (opt-in)" icon="sliders">
    Create, update, launch, and pause Meta ads. Requires the opt-in checkbox on the consent screen.
  </Card>
</CardGroup>

<Warning>
  The manage checkbox lets the assistant spend money on ads. Everything is created paused, and going live or changing budgets requires your confirmation. Leave it unchecked if you only want reads.
</Warning>

## Option 2: Local connector (advanced)

Prefer to run the connector yourself with an API key? Install the npm package and add it to your client config.

Claude Code:

```bash
claude mcp add cortana -- npx -y @cortana-ai/mcp-server@latest
```

Claude Desktop, Cursor, or VS Code config:

```json
{ "mcpServers": { "cortana": { "command": "npx", "args": ["-y", "@cortana-ai/mcp-server@latest"], "env": { "CORTANA_API_KEY": "sk-ak-your-api-key", "CORTANA_BUSINESS_ID": "your-business-id" } } } }
```

Generate an API key in Settings, then API Keys. See [Authentication](/authentication) for presets and scopes, and for finding your Business ID.
