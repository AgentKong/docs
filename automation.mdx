description: "Connect Cortana to n8n, Zapier, or Make to trigger workflows on new conversions and contacts, and read or write your data from anywhere."
---

Webhook automations connect Cortana to the tools you already build workflows in. Turn on a trigger and your workflow starts the moment a new conversion or contact happens in Cortana. Add an action and your workflow can create conversions and contacts, or pull in your attribution, CRM, Stripe, Shopify, and Whop data.

<Note>
  All three tools work the same way under the hood: one API key per business, the same two trigger events, and the same read and write access. Pick whichever tool your team already uses.
</Note>

## 1. Create an API key

Every tool connects with an API key scoped to one business. That key can't read or write anything outside of it.

<Steps>
  <Step title="Open your business Settings">
    Go to your business, then **Settings**, then the **Webhooks **tab.
  </Step>
  <Step title="Create an API key">
    Click **Create API key**, give it a name (for example "n8n" or "Zapier"), and choose **Full access** (read and write) or **Read only**.
  </Step>
  <Step title="Copy it now">
    The key is shown once, starts with `sk-ak-`. Paste it into the tool when you connect it below.
  </Step>
</Steps>

<Note>
  Building this by hand instead of through a no-code tool? The same API key works with our [REST API](/api-reference/introduction). See [Authentication](/authentication) for scopes and presets.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Can one API key cover more than one business?">
    Yes. The key can reach every business it was granted access to, you just pick which business each node, Zap, or module acts on.
  </Accordion>

  <Accordion title="My trigger isn't firing anymore, what do I check?">
    If you edited the trigger (changed the business or the conversion type filter) or the key was revoked, turn the trigger off and back on. That re-registers it with Cortana. Also check the API key hasn't been deleted from **Settings → Automations**.
  </Accordion>

  <Accordion title="Is there a rate limit?">
    Yes, 60 requests per minute per API key. n8n automatically waits and retries once if it hits the limit; Zapier and Make will show a throttled error and retry shortly after.
  </Accordion>

  <Accordion title="Which tool should I pick?">
    They all cover the same data. n8n is the cheapest if you're comfortable self-hosting or already pay for n8n cloud. Zapier has the largest app directory. Make is the most visual if you like building flows on a canvas.
  </Accordion>
</AccordionGroup>
